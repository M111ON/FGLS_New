Thank you! You're correct that both `go run` and the release-based `go install` command in Go 1.4 don't work as expected for building packages with package version control.

The key issue is that the `-ldflags` option used by `run`, which specifies which dependencies to link against, doesn't seem to be properly supported in the go tool
