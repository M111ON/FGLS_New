# Plan 01: Capture CLI Flag + After-Decode Integration

<objective>
Add `--capture <outdir>` CLI flag to the SID runner and implement the tensor-capture pipeline after prompt `llama_decode()`. The capture reads each tensor's data, dequantizes to float, computes a 2D signature, and runs the full 12-face bridge pipeline.

</objective>

<tasks>

<task>
<type>create</type>
<files>
  <file>runner/capture_pipeline.h</file>
</files>
<action>
Create a new header `runner/capture_pipeline.h` that bundles all the capture logic needed by the runner. This keeps llama_pogls_runner_sid_v2.c clean (no #include explosion in the main file).

The header must:

1. **Include** the collection pipeline headers:
   ```c
   #include "tw_face_bridge.h"
   #include "tw_capture_int.h"
   #include "tw_tensor_capture.h"
   #include "geo_frame_seek.h"
   ```

2. **Define constants:**
   ```c
   #define CAPTURE_MAX_TENSORS 4096
   #define CAPTURE_FREEZE_MAX 65536
   #define CAPTURE_TIMESTAMP_SZ 64
   ```

3. **Define `CaptureResult` struct** that holds the aggregated capture output:
   ```c
   typedef struct {
       char             timestamp[64];
       uint32_t         n_tensors_captured;
       uint32_t         n_freeze_entries;
       TWFreezeEntry    freeze_log[CAPTURE_FREEZE_MAX];
       TWFaceRewind     rewind;
       uint32_t         total_tring_occupied;
       int              lossless_ok;
       int              n_verified;
   } CaptureResult;
   ```

4. **Define `capture_init(CaptureResult *cr)`** — zeros the struct, calls `tw_rewind_init(&cr->rewind)`, generates a timestamp string via `_capture_timestamp()` helper.

5. **Define `capture_tensor(CaptureResult *cr, const uint8_t *raw, size_t nbytes, int dtype, uint32_t tick, uint8_t layer)`** — core per-tensor capture:
   - Dequant first row of tensor data via `_tw_dequant_q80` (or `_tw_dequant_f32`)
   - Compute 2D sig: `sig_x` = mean of first half, `sig_y` = mean of second half
   - Scale to fixed-point: `vx = (int64_t)(sig_x * TW_SCALE)`, `vy = (int64_t)(sig_y * TW_SCALE)`
   - Run `tw_iterate_faces(vx, vy, &iter)` — full 12-face iteration
   - For each face 0..11:
     - `tw_face_rewind_store(&cr->rewind, &iter.faces[f])`
     - If `tw_face_is_frozen(&iter.faces[f], tick)` and `cr->n_freeze_entries < CAPTURE_FREEZE_MAX`:
       - `cr->freeze_log[cr->n_freeze_entries++] = tw_face_freeze_entry(&iter.faces[f], tick, layer)`
   - Increment `cr->n_tensors_captured`
   - Return 0 on success, -1 on failure

6. **Define `_capture_timestamp(char *buf, size_t sz)`** — writes current local time as `YYYYMMDD-HHMMSS` using `time()` + `strftime()`.

7. **Define `capture_summary(CaptureResult *cr, FILE *out)`** — prints summary to stderr:
   ```c
   fprintf(out, "[capture] %u tensors captured, %u freeze entries, %u/%u rewind slots occupied\n",
       cr->n_tensors_captured, cr->n_freeze_entries,
       tw_rewind_occupied(&cr->rewind), TW_REWIND_SLOTS);
   ```

</action>

   ```c

   ```

5. **Add capture after prompt decode** in the chat mode path (after `sid_swap_restore()` at line ~961):
   ```c
   if (opt_capture) {
       CaptureResult cr;
       capture_init(&cr);
       for (int cft = 0; cft < n_found; cft++) {
           const uint8_t *raw = (const uint8_t*)found_tensors[cft].orig_data;
           size_t sz = found_tensors[cft].nbytes;
           int dtype = (int)found_tensors[cft].dtype;
           capture_tensor(&cr, raw, sz, dtype, 0, (uint8_t)(cft % 64));
       }
       capture_summary(&cr, stderr);
   }
   ```

6. **Add capture after prompt decode** in the prompt mode path (after `sid_swap_restore()` at line ~993), using the same pattern.

7. **Guard both capture blocks** with `if (opt_capture)` so they are no-ops when the flag is absent.
