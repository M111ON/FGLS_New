# Plan 02: Store Output + Lossless Verification + Demo

<objective>
Add freeze wallet (.tw) and .gsten store file writing to the capture pipeline, implement lossless byte-level verification, and produce end-to-end demos on SmolLM2-360M and one additional GGUF model.

</objective>

<tasks>

<task>
<type>modify</type>
<files>

</files>
<action>
Add store-writing and verification functions to `capture_pipeline.h`:

1. **Add `capture_write_freeze_wallet(CaptureResult *cr, const char *outdir)`**:
   - Construct path: `snprintf(path, 512, "%s/capture-%s.tw", outdir, cr->timestamp)`
   - Call `tw_freeze_wallet_write(path, cr->freeze_log, cr->n_freeze_entries)`
   - On success, print: `[capture] freeze wallet: %s (%zu bytes)\n`
   - On failure, print: `[capture] ERROR: freeze wallet write failed\n`
   - Return bytes written, or 0 on error

2. **Add `capture_write_store(CaptureResult *cr, const char *outdir, const FoundTensor *tensors, int n_tensors)`**:
   - Construct path: `snprintf(path, 512, "%s/store-%s.gsten", outdir, cr->timestamp)`
   - Open file for binary write
   - Write header containing: magic `0x474E5453` ("STNG"), version 1, n_tensors, n_freeze_entries, timestamp string (padded to 32 bytes)
   - For each found tensor: write tensor name length (uint16_t), name bytes, nbytes (uint64_t), raw data bytes
   - Write all freeze entries after tensor data
   - Close file
   - On success, print: `[capture] store: %s (%zu bytes, %d tensors)\n`

3. **Add `capture_verify(CaptureResult *cr, const FoundTensor *tensors, int n_tensors)`**:
   - For each tensor, reconstruct the original data from the stored representation
   - Compare reconstructed bytes against `found_tensors[i].orig_data` using `memcmp`
   - Count matches and mismatches
   - Find first mismatch index for error reporting
   - On first mismatch, stop and report
   - Set `cr->lossless_ok = (mismatch_count == 0)`, `cr->n_verified = n_tensors`
   - Print final line: `[capture] lossless: %s (%d tensors verified)\n` with ✓ or ✗
   - If mismatch: `[capture] first mismatch at tensor %d (%s)\n`

4. **Add `capture_run_full(CaptureResult *cr, const char *outdir, const FoundTensor *tensors, int n_tensors, uint32_t tick)`**:
   - Convenience function that runs:
     - `capture_init(cr)`
     - For each tensor: `capture_tensor(cr, raw, sz, dtype, tick, layer)`
     - `capture_write_freeze_wallet(cr, outdir)`
     - `capture_write_store(cr, outdir, tensors, n_tensors)`
     - `capture_verify(cr, tensors, n_tensors)`
     - `capture_summary(cr, stderr)`
   - This is the main entry point called from the runner

</action>
