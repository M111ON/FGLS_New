# Plan 01: Add DualFrame to Orchestrator Output

## Overview

Add `DualFrame df` field to the `TWCapture12FaceResult` struct (created in Phase 1 Plan 01) and populate it inside `tw_capture_tensor_12face()` with a single `frame_at()` call. This completes the bridge between geometric capture coordinates and the `geo_frame_seek.h` 1440-position frame timeline.

**Decisions covered:** D-08 (integrate into orchestrator), D-09 (direct `frame_at` call, no wrapper).

</threat_model>

### Task 02-01-01: Populate df in tw_capture_tensor_12face()

<action>
Inside `tw_capture_tensor_12face()`, after the `tw_capture_priority()` call resolves `best` (TWFaceCapture) and before the rewind store, add the frame seek call:

```c
    /* Populate DualFrame from geo_frame_seek.h */
    out->df = frame_at(best.tring_pos);
```

Insert after the `tw_capture_priority` call and before `tw_face_rewind_store`. The full sequence becomes:

```c
    TWFaceCapture best;
    int n_faces = tw_capture_priority(vx, vy, &best, 7);

    /* FRAME TIMELINE: TRing position → DualFrame (O(1), stateless) */
    out->df = frame_at(best.tring_pos);

    /* Store best capture in rewind buffer */
    tw_face_rewind_store(&out->rewind, &best);
```

The call is O(1) integer decomposition — no state, no allocation, no error path.
`frame_at()` is already included via `geo_frame_seek.h` (included at line 45 of `tw_face_bridge.h`).
</action>
