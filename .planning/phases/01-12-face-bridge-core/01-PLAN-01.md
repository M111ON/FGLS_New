# Plan 01: Orchestrator Function

## Overview

Create the `tw_capture_tensor_12face()` orchestrator function that wraps `tw_tensor_capture_tensor_by_name()` → `tw_capture_priority()` → rewind store + freeze wallet in a single call. Adds `TWCapture12FaceResult` struct and `tw_capture_12face_free()` cleanup function.

**Decisions covered:** D-01 (TRing 1440), D-02 (priority 7 faces), D-03 (fixed TW_FACE_PRIORITY order), D-04 (orchestrator wraps both steps), D-05 (single-pass rewind + freeze).

### Task 01-01-02: Implement tw_capture_tensor_12face()

<action>
Add after the init/free functions in `collection/tw_face_bridge.h`:

```c
static inline int tw_capture_tensor_12face(
    RawBridge *rb, const char *tensor_name,
    uint32_t tick, uint8_t layer,
    TWCapture12FaceResult *out)
{
    TWTensorCapture tc;
    if (tw_capture_tensor_by_name(rb, tensor_name, &tc) != RB_OK)
        return -1;

    int64_t vx = (int64_t)(tc.sig_x * TW_SCALE);
    int64_t vy = (int64_t)(tc.sig_y * TW_SCALE);

    TWFaceCapture best;
    int n_faces = tw_capture_priority(vx, vy, &best, 7);

    /* Store best capture in rewind buffer */
    tw_face_rewind_store(&out->rewind, &best);

    /* Ensure freeze_log capacity */
    if (tw_face_is_frozen(&best, tick)) {
        if (out->n_frozen >= out->freeze_cap) {
            uint32_t new_cap = out->freeze_cap ? out->freeze_cap * 2 : TW_MAX_FROZEN_PER_TENSOR;
            TWFreezeEntry *new_log = (TWFreezeEntry *)realloc(
                out->freeze_log, new_cap * sizeof(TWFreezeEntry));
            if (!new_log) return -1;
            out->freeze_log = new_log;
            out->freeze_cap = new_cap;
        }
        out->freeze_log[out->n_frozen++] = tw_face_freeze_entry(&best, tick, layer);
    }

    /* Track global best */
    int64_t mag2 = (int64_t)best.resid_x * best.resid_x
                 + (int64_t)best.resid_y * best.resid_y;
    if (out->n_tensors == 0 || mag2 < out->best_mag2) {
        out->best = best;
        out->best_mag2 = mag2;
    }
    out->n_tensors++;

    return 0;
}
```

Key design choices:
- Uses `tw_capture_priority()` with 7 faces (D-02, D-03)
- Freeze_log uses realloc for dynamic growth (starts at 7 entries)
- Caller must call `tw_capture_12face_free()` at end
- Single-pass to both rewind buffer AND freeze wallet (D-05)

### Task 01-01-03: Add multi-tensor batch function

<action>
Add after `tw_capture_tensor_12face()`:

```c
static inline int tw_capture_tensor_12face_batch(
    RawBridge *rb,
    const char **tensor_names, uint32_t n_tensors,
    uint32_t tick, uint8_t layer,
    TWCapture12FaceResult *out)
{
    if (!rb || !tensor_names || !out) return -1;
    tw_capture_12face_init(out);

    for (uint32_t i = 0; i < n_tensors; i++) {
        int rc = tw_capture_tensor_12face(rb, tensor_names[i], tick, layer, out);
        if (rc != 0) continue; /* skip tensors with loading errors */
    }

    return (out->n_tensors > 0) ? 0 : -1;
}
```
