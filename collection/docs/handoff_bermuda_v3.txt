CROSS SELF-INVERSE FIX
════════════════════════════════════════════════════════════

Bug (v1/v2): WALK_LEN=720 hardcoded → idx ≥ 720 collides for gear≥2
Bug (v3 first attempt): invert in slots-space ≠ WL-space

Fix (final):
  enc   = (idx * 37) % WL              # work in WL-space
  zone  = enc // face_sz
  pz    = CROSS_LUT[zone % 12]
  ne    = pz * face_sz + enc % face_sz
  idx1  = (ne * INV_WL) % WL % slots   # invert in WL-space, clip to slots

FULL PIPELINE (bermuda_pass_v3)
════════════════════════════════════════════════════════════

def bermuda_pass_v3(gate, x, out_shape, mode):
  1. snap_gear(N)           → gear
  2. pad_to_gear()          → x_padded, pad_len  (padding reserve)
  3. hilbert_scatter()      → reorder by stride-37 walk
  4. strip()                → core, offset, shadow
  5. gate(core, mode)       → core_out, idx_in, idx_out  (semantic)
  6. reattach()             → core_out + shadow + offset
  7. hilbert_gather()       → restore original order
  8. unpad()                → shed padding reserve
  9. reshape(out_shape + D) → final tensor

Shadow Protocol (unchanged from v2):
  offset = per-token mean  [N, 1]
  shadow = residual vs batch mean  [N, D]
  BermudaSnapshot = {offset, shadow, idx_in, orig_shape, out_shape, gear, mode, pad_len}

Traverse modes:
  ORBITAL  (+1)       local step
  CHIRAL   (+N//2)    mirror zone
  CROSS    (LUT+WL)   self-inverse entangled pair
  HUB      (→anchor)  collapse to zone anchor
