SHADOW PROTOCOL (bermuda_reshape_v2.py)
════════════════════════════════════════════════════════════

Metal detector analogy:
  core   = ตัวคน    (geometry-passable signal)
  shadow = กระเป๋า  (residual, ห้อยรอข้างนอก gate)
  offset = เข็มขัด  (per-token mean, scale/bias)
  snapshot = ตั๋ว   (ticket พิสูจน์ topology ไม่แตก)

Functions:
  strip(x_flat)  → core, offset, shadow
    offset = x.mean(dim=-1, keepdim=True)       [N, 1]
    core   = x - offset - batch_mean            [N, D]
    shadow = residual vs batch mean             [N, D]

  reattach(core_out, snap) → x_out
    x_out = core_out + shadow.reshape(N,D) + offset.reshape(N,1)

  bermuda_pass(gate, x, out_shape, mode) → x_out, BermudaSnapshot
    full pipeline: strip → gate → reattach → reshape

BermudaSnapshot dataclass:
  offset, shadow, idx_in, orig_shape, out_shape, mode

Key result from experiments:
  [1] valid=True all modes — topology never breaks
  [2] [4,16,128]→[8,8,128] valid all modes ✓
  [3] HUB collapse → ≤12 unique positions (zone anchors) ✓
  [4] CROSS self-inverse: 100% after fix ✓
  [5] 2-gate pipeline [6,8]→CHIRAL→[4,12]→CROSS→[6,8] valid ✓
