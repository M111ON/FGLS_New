ARCHITECTURE:
  v4: Fixed 64B chunks → Hilbert traversal → smart_encode (FLAT/RAW/DIAMOND/BATCH/GEOM)
  v5: Same + transform detection between consecutive traversal-order chunks
      Tags: 0=FLAT 1=RAW 2=DIAMOND 3=BATCH 4=GEOM 5=IDENTITY 6=BROT 7=BREF 8=D4 9=DIFF
  v6: Flow chunker splits input at geometric dead zones (isect==0)
      Each zone encoded independently → state reset at zone boundaries

KEY RESULTS:
  - 64B pattern x512: v5=50.88x (IDENTITY: 1B) vs v4=12.19x (BATCH: 5B)
  - Zeros 16KB: 50.57x (FLAT + IDENTITY chain)
  - Source code (pogls_fold.h): 1.42x (DIFF catches similar consecutive chunks)
  - Random: 0.99x (no compression, header overhead)

  .\diamond_geo_pipe_v5.exe roundtrip <input.bin>
