# Prompt Engineering Expert Skill

This skill equips the agent with deep expertise in prompt engineering, custom instructions design, and prompt optimization. It provides comprehensive guidance on crafting effective AI prompts, designing agent instructions, and iteratively improving prompt performance.

## When to use
- User asks to analyze, review, or improve a prompt
- User wants to create a system prompt or custom instructions for an agent/skill
- User needs guidance on prompt engineering techniques (CoT, few-shot, XML tags, role-based, etc.)
- User reports inconsistent outputs, hallucinations, or other prompt issues
- User wants to design a testing/evaluation framework for prompts
- User asks about prompt engineering best practices or anti-patterns
